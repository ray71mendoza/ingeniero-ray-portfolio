## ✨ Sobre Este Proyecto

Portafolio web profesional desarrollado en **Angular 20+** como demostración de nivel **Senior / Arquitecto de Software**. Diseñado con el sistema visual *"Cyber Luxury"* — glassmorphism, glow effects neón, animaciones GSAP, y modo oscuro/claro con identidades completamente distintas.

> Construido con los más altos estándares de ingeniería, rendimiento y experiencia de usuario — al nivel de Vercel, Linear y Stripe.

## 🚀 Instalación y Uso Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/tu-usuario/portafolio-ray.git
cd portafolio-ray

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run start

# 4. Compilar para producción
npm run build
```

---

## 📦 Deploy en Vercel

1. Conecta el repositorio a [Vercel](https://vercel.com)
2. Framework Preset: **Angular**
3. Vercel detecta automáticamente `vercel.json` para SPA routing
4. ¡Deploy automático en cada push a `main`! 🎉
